# Sales Data Automation & Report Generator

This is a Python project I built to practice working with CSV files and automating simple sales reports.

The program reads sales data from a CSV file, checks the data, calculates total sales, finds the best-selling product, and creates a new report automatically.

## What It Does

- Reads sales records from a CSV file
- Checks for invalid data
- Calculates total sales
- Calculates total items sold
- Finds the best-selling product
- Shows sales by product
- Generates a new `sales_report.csv` file
